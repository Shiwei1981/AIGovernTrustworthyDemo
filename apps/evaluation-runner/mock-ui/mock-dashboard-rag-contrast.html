Contrast conclusion

  • Both targets are useful for content grounded in the same five PDFs.
  • RAG service is easier to audit because citation metadata is more stable.
  • Agent quality can still be acceptable even when citation_present=false; the dashboard should show that explicitly instead of treating it as unknown.
