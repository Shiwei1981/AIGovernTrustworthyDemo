# Cross-App Architecture Charter

本文件用于编写跨应用程序开发宪章。所有应用、共享包、基础设施脚本和设计文档都应遵守这里定义的统一规则。

## 1. 宪章目标

在此说明本宪章要解决的问题、适用范围，以及哪些团队或目录必须遵守。

## 2. 应用边界

在此定义：

- 各应用的职责边界
- 允许直接依赖哪些共享包
- 不允许跨应用直接访问哪些内部实现

## 3. 共享能力

在此定义哪些能力必须统一复用，例如：

- APIM 作为统一外部入口
- Application Insights 作为统一证据与遥测汇聚点
- 共用身份模型、日志字段、错误码或追踪规则

## 4. 统一契约

在此定义跨应用必须统一的契约，例如：

- API 约定
- 遥测字段
- 环境变量命名
- Target registry / evaluation 数据结构

## 5. 可观测性与调用链

在此定义：

- 哪些应用必须接入 OpenTelemetry
- `service.name` 如何命名
- 哪些 trace / span / correlation 字段必须统一
- 哪些事件必须写入 Application Insights

## 6. 身份与访问控制

在此定义：

- 哪些应用必须使用独立运行时 SPN
- 哪些权限可以共享，哪些必须隔离
- 哪些资源访问必须经过 APIM 或受控网关

## 7. 禁止事项

在此列出禁止出现的跨应用耦合方式，例如：

- 直接依赖其他应用私有数据库或私有内部模块
- 绕过 APIM 直接暴露外部测试入口
- 不经过统一契约新增隐式接口

## 8. 变更规则

在此定义：

- 什么类型的改动必须同步更新本宪章
- 谁负责审批跨应用规则变化
- 违反宪章时如何处理
