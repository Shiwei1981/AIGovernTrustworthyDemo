# AIGovernDashboardDesign

本目录用于沉淀 AI Governance Dashboard 的设计过程产物，而不是放应用实现代码。

建议使用方式：

- `00-charters/`：设计阶段需要遵守的跨文档约束、设计边界、强制原则。
- `01-methodology/`：方法论拆解、框架映射、外部输入整理。
- `02-research/`：调研笔记、资料摘录、问题清单。
- `03-ia-and-kpis/`：栏目结构、页面结构、KPI 设计、指标口径。
- `04-ux-and-prototypes/`：交互草案、原型说明、假数据页面。
- `05-decisions/`：设计决策记录、争议点、取舍说明。

本目录和 `docs/` 的关系：

- `docs/` 是项目级需求与约束的权威来源。
- `AIGovernDashboardDesign/` 是设计工作区，用于逐步沉淀调研、思考、确认过程和中间产物。
